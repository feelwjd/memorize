# 📦 프로젝트 개요

이 저장소는 다음과 같은 세 가지 주요 프로젝트를 포함하고 있습니다:

1. **bizmob-appstore**: 앱 스토어 서비스.
2. **bizmob-portal**: 포털 서비스.
3. **bizmob-mobile-server**: 모바일 서버 서비스.


각각의 프로젝트는 Docker 이미지를 생성하고 SAP BTP 환경에 배포하기 위한 설정 파일을 포함하고 있습니다.

## 📝 각 프로젝트 설명
1. bizmob-appstore
- 설명: 애플리케이션 스토어 서비스로, 사용자는 다양한 앱을 검색하고 설치할 수 있습니다.
- 주요 파일:
    - Dockerfile: Docker 이미지를 빌드하는 데 필요한 명령어가 포함되어 있습니다.
    - manifest.yml: SAP BTP 환경에 애플리케이션을 배포하기 위한 설정 파일입니다.
    - appstore.war: 앱스토어 애플리케이션 배포 파일입니다.
    - SMART_HOME: 어플리케이션 설정 파일 및 로그 파일이 포함되어 있는 폴더입니다.
        - application.properties: 파일 업로드 저장소 설정, DB 설정이 포함되어 있습니다.
        - logback.xml: 로그를 기록하는 logback 설정 파일입니다. 기본적으로 SMART_HOME/logs/ 하위 폴더로 저장되도록 설정되어 있습니다. (수정 가능)

2. bizmob-portal
- 설명: 포털 서비스로, 관리자가 다양한 서비스를 관리하고 모니터링할 수 있는 인터페이스를 제공합니다.
- 주요 파일:
    - Dockerfile: Docker 이미지를 빌드하는 데 필요한 명령어가 포함되어 있습니다.
    - manifest.yml: SAP BTP 환경에 애플리케이션을 배포하기 위한 설정 파일입니다.
    - smart-admin.war: 포털 애플리케이션 배포 파일입니다.
    - SMART_HOME: 어플리케이션 설정 파일 및 로그 파일이 포함되어 있는 폴더입니다.
        - application.properties: 파일 업로드 저장소 설정, DB 설정이 포함되어 있습니다.
        - logback.xml: 로그를 기록하는 logback 설정 파일입니다. 기본적으로 SMART_HOME/logs/ 하위 폴더로 저장되도록 설정되어 있습니다. (수정 가능)

3. bizmob-mobile-server
- 설명: 모바일 장치와 통신하는 서버 애플리케이션입니다.
- 주요 파일:
    - Dockerfile: Docker 이미지를 빌드하는 데 필요한 명령어가 포함되어 있습니다.
    - manifest.yml: SAP BTP 환경에 애플리케이션을 배포하기 위한 설정 파일입니다.
    - 여러 Java 및 XML 구성 파일들이 포함되어 있으며, 각 모듈 (adapter, model, web)별로 분리되어 있습니다.


## 🛠 Docker 이미지 빌드 방법

- Docker 설치 및 운영 환경 구성

- Maven 설치 (또는 IDE 내 maven 사용)
	- https://maven.apache.org/download.cgi 

각 프로젝트 디렉토리 내에서 다음 명령어를 실행하여 Docker 이미지를 빌드할 수 있습니다:

PS_) 현재 개인 Docker Hub에 이미지를 배포하여 받아오고 있는데, Private 설정이 필요합니다.
아래의 두 방법 중 하나를 추천드립니다.
- CESCO Docker 계정을 통해서 이미지를 Hub에 배포하는 방식
- Private Registry를 구축하여 배포하는 방식 
	- https://docs.docker.com/reference/cli/docker/login/

## ☁️ SAP BTP로 배포하는 방법
각 프로젝트의 manifest.yml 파일을 사용하여 SAP BTP에 애플리케이션을 배포할 수 있습니다. 배포를 위해 Cloud Foundry CLI (cf cli)가 필요합니다.

### 1. Cloud Foundry CLI 설치
Cloud Foundry CLI 설치 가이드를 참고하여 시스템에 cf 명령어를 설치합니다.

- https://docs.cloudfoundry.org/cf-cli/install-go-cli.html

### 2. SAP BTP 로그인
SAP BTP 환경에 로그인합니다:

```bash
cf login
```

### 3. 애플리케이션 배포
각 프로젝트 디렉토리에서 다음 명령어를 실행하여 애플리케이션을 배포합니다:

```bash
# bizmob-appstore 디렉토리로 이동
cd bizmob-appstore

# 애플리케이션 배포
cf push
```
```bash
# bizmob-mobile-server 디렉토리로 이동
cd bizmob-mobile-server/cesco-server

# 애플리케이션 배포
cf push
```
```bash
# bizmob-portal 디렉토리로 이동
cd bizmob-portal

# 애플리케이션 배포
cf push
```
### 4. 배포 상태 확인
배포 후 애플리케이션 상태를 확인하려면 다음 명령어를 사용하세요:

```bash
cf apps
```

### ℹ️ 추가 참고 사항
각 프로젝트의 manifest.yml 파일은 SAP BTP 환경에 맞게 미리 구성되어 있어야 합니다.
애플리케이션에 대한 특정 구성 및 환경 변수는 manifest.yml 파일에서 설정할 수 있습니다.

예시)

```yml
---  
applications:  
  - name: bizmob-mobile-server  
    memory: 2048M  
    docker:  
      image: feelwjd/bizmob-mobile-server-app:latest  
    env:  
      JAVA_OPTS: "-Dfile.encoding=UTF-8 -Dsun.jnu.encoding=UTF-8"
```

## Application Run/Stop - CLI
- CLI 명령어를 사용해 애플리케이션 실행 및 중지 관리
- 애플리케이션 관리:
    
    - `cf push APP_NAME`: 애플리케이션 배포
    - `cf start APP_NAME`: 애플리케이션 시작
    - `cf stop APP_NAME`: 애플리케이션 중지
    - `cf restage APP_NAME`: 애플리케이션 재배포
    - `cf delete APP_NAME`: 애플리케이션 삭제
    
- 서비스 관리:
    
    - `cf marketplace`: 사용 가능한 서비스 목록 표시
    - `cf create-service SERVICE PLAN SERVICE_INSTANCE`: 서비스 인스턴스 생성
    - `cf bind-service APP_NAME SERVICE_INSTANCE`: 애플리케이션에 서비스 인스턴스 바인딩
    - `cf unbind-service APP_NAME SERVICE_INSTANCE`: 애플리케이션에서 서비스 인스턴스 언바인딩
    - `cf delete-service SERVICE_INSTANCE`: 서비스 인스턴스 삭제
    
- 애플리케이션 로그 및 상태:
    
    - `cf logs APP_NAME`: 애플리케이션 로그 보기
    - `cf app APP_NAME`: 애플리케이션 상태 정보 확인
    - `cf events APP_NAME`: 애플리케이션 이벤트 표시
    
- 공간 및 조직 관리:
    
    - `cf create-space SPACE_NAME`: 공간 생성
    - `cf target -o ORG_NAME -s SPACE_NAME`: 조직 및 공간 전환
    - `cf spaces`: 사용 가능한 공간 목록 표시
